### Eramba DB Commands — Short List

```sql
USE docker;
```

**Use:** Select Eramba database.

```sql
SHOW TABLES;
```

**Use:** List all tables.

```sql
DESCRIBE table_name;
```

**Use:** Check table columns.

```sql
SHOW CREATE TABLE table_name;
```

**Use:** Check exact table structure.

```sql
SELECT * FROM table_name LIMIT 10;
```

**Use:** View sample data.

```sql
SELECT COUNT(*) FROM table_name;
```

**Use:** Count records.

### Risk Classification

```sql
SELECT * FROM risk_classification_types;
```

**Use:** Check classification types.

```sql
INSERT INTO risk_classification_types
(id,name,risk_classification_count)
VALUES
(1,'Type 1',3),(2,'Type 2',3);
```

**Use:** Create Type 1/Type 2.

### Policy Error Fixes

```sql
ALTER TABLE security_policies
MODIFY document_type VARCHAR(255) NULL;
```

**Use:** Fix `document_type` error.

```sql
ALTER TABLE reviews
MODIFY description TEXT NULL;
```

**Use:** Fix `reviews.description` error.

```sql
ALTER TABLE projects_security_policies
MODIFY created DATETIME NULL;
```

**Use:** Fix policy-project `created` error.

### MySQL Settings

```sql
SET GLOBAL sql_mode =
REPLACE(@@GLOBAL.sql_mode,'ONLY_FULL_GROUP_BY','');
```

**Use:** Fix `GROUP BY` error.

```sql
SET GLOBAL max_allowed_packet=128000000;
```

**Use:** Increase packet size.

```sql
SET GLOBAL innodb_lock_wait_timeout=200;
```

**Use:** Increase DB lock wait time.

### Check Settings

```sql
SHOW GLOBAL VARIABLES LIKE 'max_allowed_packet';
SHOW GLOBAL VARIABLES LIKE 'innodb_lock_wait_timeout';
SELECT @@GLOBAL.sql_mode;
```

### ⚠️ Full Reset — Don't use unless required

```sql
DROP DATABASE docker;
CREATE DATABASE docker;
```

**Use:** Completely wipe and recreate Eramba DB.
